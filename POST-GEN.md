# Post-gen: from a Suno clip to a song

Starting checklist for what happens after generation. Draft for Zaal to shape. Log every step you take in the generation file's Post-production table: what, which tool, who, and where the output file lives.

## 1. Pick

- Listen to every clip on headphones and a phone speaker.
- Pick the take with the best performance and hook, not the busiest arrangement.
- Write down why, and what still bugs you.

## 2. Fix inside Suno (before export)

- Song Editor: crop, fades, replace or add a section for a bad bar or line.
- Extend if it ends too early; Remaster (Subtle / Normal) for a cleaner print without changing the song.
- Cover only for a bigger restyle. Each of these spends credits: log them.

## 3. Export

- WAV, not MP3. Stems if you will mix (vocals, drums, bass, other).
- Name files `<song>-gen<N>-<clip>-<stem>.wav` and keep them in one folder. Note the folder in the log.

## 4. Edit (DAW)

- Tempo-map at the measured BPM. Trim the start to the first downbeat.
- Arrange: cut dead bars, tighten intros for battles and DJ sets, make a clean radio edit if needed.
- Fix vocal artifacts (clicks, warble, smeared consonants) or mute and replace them.

## 5. Mix

- Follow the DAW checklist in `SKILL.md`: gain staging, low end, subtractive EQ, balance before effects, vocal on top, width with a mono check.
- Reference against one commercial track in the same lane.

## 6. Master

- Streaming: about -14 LUFS integrated, true peak below -1 dBTP.
- Listen on headphones, small speakers and a phone. If it only works slammed, fix the mix.

## 7. Release pack

- Final WAV and MP3, cover art, title, credits (who did what, AI tools used), lyrics.
- Where it goes: WaveWarZ battle upload, streaming, socials. Nothing is published without Zaal's go.

## 8. Log

- Fill the generation file's Post-production table and update `songs/INDEX.md`.
